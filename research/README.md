# Research notes

Questions examined while learning: a difficult Rashi, a contradiction between
sources, how a Rishon or the Rambam learns a sugya. These notes are not part of
the app.

## Format

- **One file per sugya**, named `<tractate>-<daf><amud>-<topic>.md`. The
  tractate is spelled as on Sefaria in lowercase with hyphens
  (`arakhin`, `bava-kamma`). Follow-up questions on the same sugya go into the
  same file as the next numbered question.
- **Quote, don't paraphrase.** Give the exact words of every source, with its
  reference and, where it matters, the edition. Quote each key text once under
  "The texts" and refer back to it.
- **Say what wasn't checked**: works not on Sefaria, and anything known only
  second-hand ("the Rosh, as quoted by the Kesef Mishneh").
- **Never silently rewrite an answer that turned out wrong.** Leave it and add
  a dated line under "Corrections".
- Notes are in English. Hebrew and Aramaic are quoted without nikud.
